\paragraph{SE interval width.} SE interval width is the distinctively imprecise output of the threshold construction, and the MMLU/ARC registration predicted that it would rise with difficulty (H4). It does not: Spearman $\rho$ is $-0.54$ on MMLU and $-0.46$ on ARC-Challenge. Its AUROC for majority-vote error is .479 on NQ-Open and .385 on TruthfulQA, and its AUROC for the 1--2/6 bin is .474 on NQ-Open, .514 on TruthfulQA, and .252 on ARC-Challenge (post hoc). So it does not flag errors, and where it carries a signal it runs the wrong way. The next paragraph accounts for the multiple-choice values.
